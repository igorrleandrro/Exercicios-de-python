Cálculo de Média Escolar e Classificação de Notas (Python)

Este projeto foi desenvolvido para praticar o processamento de dados estatísticos simples e a classificação de elementos em uma lista. O programa lê uma quantidade $N$ de notas de alunos, calcula a média geral da turma e exibe a quantidade exata de estudantes que ficaram acima, abaixo e na média.

## O que foi praticado neste exercício:
* **Estruturas de Repetição Desacopladas:** Uso de um laço `for` focado na coleta e acumulação de dados, e um segundo laço para a análise comparativa dos elementos.
* **Classificação Condicional:** Uso de condicionais para segmentar os dados da lista em três categorias distintas (acima, abaixo e na média).
* **Métricas Estatísticas Básicas:** Aplicação de conceitos de média aritmética para extração de indicadores sobre o conjunto de dados.
